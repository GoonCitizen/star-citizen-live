# Map background assets

Imagery under `assets/map/tiles/` is **not** Roberts Space Industries / Cloud Imperium
art. Catalog positions and names come from the wiki / scunpacked dump; backgrounds
are separate.

## Default tiles (in this repo)

Generated by `npm run generate:map-assets` (`scripts/generate-map-assets.js`) —
procedural starfields and nebula tints, redistributable with this project.

## Optional drop-in (CC0)

You may overwrite the same filenames with tiles from **Screaming Brain Studios —
[Seamless Space Backgrounds](https://screamingbrainstudios.itch.io/seamless-space-backgrounds)**
(512×512 pack), released as **CC0 / Public Domain**. Keep `manifest.json` paths
unchanged.

Suggested mappings:

| File | SBS category (example) |
|------|-------------------------|
| `starfield-01.png` / `starfield-02.png` | Starfields |
| `nebula-blue-01.png` | Blue Nebulas |
| `nebula-purple-01.png` | Purple Nebulas |
| `nebula-green-01.png` | Green Nebula |

Surface tiles (`surface-*.png`) are style fallbacks. **Per-body terrain** lives
under `tiles/bodies/<slug>.png` (equirectangular, one file per orbital body).
Generated by `npm run generate:map-assets` from `functions/bodyTerrain.js` —
deterministic procedural stand-ins so POIs and fleet markers sit on readable
terrain. **Not** CIG / in-game planet textures.

Operators may overwrite `tiles/bodies/<slug>.png` with licensed extracts (paths
in `manifest.json` `bodies` stay stable). Do not commit RSI art to this repo.

## Surface coordinates (lat/lon / local XYZ)

Bundled under `data/starmap/` from **[starmap.space](https://starmap.space)**
(Meridian / Eureka) community APIs (`/api/v2/oc`, `/api/v2/pois`). Refresh with
`npm run refresh:starmap-space`. These are **not** official CIG data and **not**
their terrain textures — coordinates and object-container radii only. Credit
starmap.space when redistributing.

## Later (not shipped)

NASA SVS public-domain starfields (e.g. “An Elsewhere Starfield”) may be added
as equirect / print JPGs for 3D skyboxes — keep EXR out of the repo.
