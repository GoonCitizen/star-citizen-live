# starmap.space cache

Community object-container + POI coordinates from
[starmap.space](https://starmap.space) (Meridian / Eureka).

- `oc.json` — body radii / system positions (`/api/v2/oc`)
- `pois.json` — surface lat/lon + local XYZ km (`/api/v2/pois`)
- `meta.json` — fetch metadata

Refresh: `npm run refresh:starmap-space`

Not CIG official; coordinates only (no their textures). See
`assets/map/ATTRIBUTION.md`.
